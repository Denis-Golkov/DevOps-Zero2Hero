## Create a new NodeJs application
- We are going to use nmp package name 'express-generator' to create a new NodeJs application.
  
```sh
# Install express-generator globaly:
npm install -g express-generator

# Create a new nodeJs application using express-generator:
express --view=ejs myapp

# Change directory to myapp:
cd myapp

#Install dependencies:
npm install

# Open webbrowser and enter:
localhost:3000
```
